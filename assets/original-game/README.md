# Bring your own game

Place a legally obtained original MechWarrior (1989 DOS) installation here,
or pass an external directory to the launcher/tools. Everything except this
README and the ignore file is ignored. The installation is never bundled.

The reconstructed game and executable-authored model/animation inspection need
the supported original BTECH.EXE/MW_MAIN.EXE as well as resource files. Do not
replace them with the port executable or download an installation from this repo.
Use private working copies when testing edited resources; keep original media safe.
